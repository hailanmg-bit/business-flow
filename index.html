能力开关

数据

数据保存在本机浏览器的 IndexedDB（随仓库的 sql.js 在本地运行，不上传）。清空会删除全部业务数据并恢复演示素材。

隐私说明

本应用为纯前端网页：数据库（SQLite/wasm）在浏览器内运行，AI 调用由浏览器直连 DeepSeek。没有后端服务器，业务数据不会离开你的设备；唯一出网请求是带 Key 的模型调用。如担心 Key 泄露，可随时在上方更换或删除。

欢迎使用业务通（网页版）

这是一个完全在本机运行的乙方业务流程管理工具。要启用 AI 助手，请填入你的 DeepSeek API Key（在 platform.deepseek.com 获取）。

Key 仅存于本浏览器，不会上传到任何服务器。也可先「跳过」，之后在设置页填写。
